# 练气期（0~6个月）· 凡尘入道

> 目标：从零基础，到能独立管理一台 Linux 服务器、看得懂日志、会用 Git 协作。
> 出关标准：完成三层突破考核，即可踏入筑基。

---

## 练气一层 · 道基初成（0~2个月）

> 定位：学徒。此层重在建立「计算机世界观」，把地基打牢。

### 📜 功法（按顺序修炼）
1. 计算机基础：CPU / 内存 / 磁盘 / 网卡 / 进程 是什么
2. 安装 Linux（推荐 CentOS Stream / Ubuntu Server / 国产 openEuler），虚拟机方式（VMware / VirtualBox / KVM）
3. Linux 目录结构（/、/etc、/var、/home、/proc 等）与文件类型
4. 常用基础命令：`ls` `cd` `pwd` `cat` `mkdir` `cp` `mv` `rm` `find` `grep` `tail`
5. 学会看系统信息：`uname` `lscpu` `free` `df` `uptime`

### 💠 修为经验（必会知识点）
- Linux 一切皆文件；绝对路径与相对路径
- 命令格式：`命令 [选项] [参数]`，善用 `man` / `--help`
- 重定向 `>` `>>` 与管道 `|` 的含义
- 关机/重启/注销的正确姿势（`systemctl` 时代少用 `shutdown` 硬关）

### ⚔️ 实操历练（预计 30 小时）
- 装一台 Linux 虚拟机，配好静态 IP，能通过终端 SSH 连入
- 用 `find` + `grep` + `tail` 完成一次「日志找错」练习
- 把根目录所有一级目录的作用整理成自己的笔记

### 🗡️ 武器
- VMware / VirtualBox（虚拟机）｜Xshell / Termius（终端）｜[awesome-cheatsheets](https://github.com/LeCoupa/awesome-cheatsheets)（速查表）

### 🔥 突破条件
- [ ] 能在 10 分钟内装好一台 Linux 虚拟机并联网
- [ ] 不看笔记说出 20 个常用命令的作用
- [ ] 能用管道组合 3 个命令完成一次文本处理任务

---

## 练气二层 · 灵气外放（2~4个月）

> 定位：学徒。此层修炼「控制力」——权限、用户、文本、进程。

### 📜 功法（按顺序修炼）
1. 用户与用户组：`useradd` `usermod` `groupadd` `passwd` `su` `sudo`
2. 文件权限：rwx、`chmod`（数字法与符号法）、`chown`、umask、特殊权限
3. 文本三剑客：`grep` `sed` `awk`（先会用，不要求精通）
4. vim 编辑器：普通/插入/可视模式、查找替换、多文件
5. 进程管理：`ps` `top` `htop` `kill`、后台运行 `&` `nohup` `screen` `tmux`
6. 软件包管理：yum/dnf 与 apt 的基本增删查

### 💠 修为经验（必会知识点）
- 权限位数字换算（rwx = 421）；为什么目录需要 x 权限
- sudo 与 su 的区别；root 不是用来日常操作的
- 进程状态（R/S/D/Z）；僵尸进程怎么处理
- 软链接 vs 硬链接；环境变量 PATH 的作用

### ⚔️ 实操历练（预计 40 小时）
- 创建 3 个用户、2 个组，配置目录组协作权限（755/775/770 场景）
- 用 sed/awk 从一份日志里提取指定字段并统计
- 写一个 vim 配置并熟练完成「改 10 处配置」的练习
- 把一个服务进程在 tmux 里跑起来，断开重连不丢

### 🗡️ 武器
- [htop](https://github.com/htop-dev/htop)（进程查看）｜[glances](https://github.com/nicolargo/glances)（系统监控）｜[wtf](https://github.com/wtfutil/wtf)（终端仪表盘）

### 🔥 突破条件
- [ ] 15 分钟内完成一次「新增用户 → 授权目录 → 测试权限」全流程
- [ ] 能解释 `chmod 644` `chmod 755` `chmod 4755` 的含义并说出场景
- [ ] 用 awk 从日志中统计出各状态码出现次数

## 练气三层 · 气贯周天（4~6个月）

> 定位：准运维。此层打通「任督二脉」——网络与协作。

### 📜 功法（按顺序修炼）
1. 网络基础：TCP/IP 四层模型、IP 地址、子网掩码、网关、DNS
2. 常用排障：`ping` `telnet` `nc` `curl` `dig` `traceroute`
3. HTTP/HTTPS：请求方法、状态码、报文结构
4. SSH 深入：密钥认证、端口修改、`scp` / `rsync`
5. 防火墙：firewalld 基本规则（放行/拒绝/端口转发）
6. Git 入门：clone / add / commit / push / pull / branch

### 💠 修为经验（必会知识点）
- 一次 HTTP 请求从输入 URL 到页面返回的完整链路
- 常见状态码：200 / 301 / 302 / 403 / 404 / 500 / 502 / 504
- SSH 免密登录原理（公私钥）；为什么生产环境禁用 root 密码登录
- Git 工作区 / 暂存区 / 版本库的关系

### ⚔️ 实操历练（预计 40 小时）
- 自己画一遍「浏览器输入网址 → 打开页面」的完整链路图
- 用 curl 抓取接口并解析响应头；模拟一次 404 和 502 场景并排查
- 配置 SSH 密钥免密登录，并用 rsync 完成一次增量同步
- 在 GitHub 建仓库，完成一次 PR 流程（提交 → 分支 → 合并）

### 🗡️ 武器
- [httpie](https://github.com/httpie/cli)（HTTP 客户端）｜[goreplay](https://github.com/probelabs/goreplay)（流量捕获回放）｜Git（版本控制）

### 🔥 突破条件
- [ ] 能独立排查「网站打不开」问题（网络/防火墙/DNS/服务逐层排除）
- [ ] 完成 SSH 密钥免密 + 禁 root 密码登录 + 改端口加固
- [ ] 用 Git 完成一次多人协作提交（含冲突解决）

---

## 🎓 练气出关

完成三层突破条件后，你已具备：一台服务器管理能力、日志排障能力、版本协作能力。
**恭喜踏入筑基期，开始系统运维的正式修行。**
