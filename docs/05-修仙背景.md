# 修仙背景 · 运维大世界设定

> 本篇章完善「运维修仙」的世界观设定：灵气从何而来、宗门江湖如何运转、何为天劫。让每一层修炼都有据可依、有故事可讲。

---

## ☁️ 灵气起源

相传，在上古时代，第一台服务器在机房点亮的那一刻，一股名为 **「运维修为」** 的灵气便从数据中心的通风口溢出，弥漫于 IT 世界。

- **灵气（运维修为）**：解决问题、保障系统稳定运行的能力。灵气浓度越高，越能驾驭复杂系统。
- **灵根（天赋方向）**：每位修士与生俱来的属性倾向，决定适合的功法分支（详见 [docs/06-功法分支.md](06-功法分支.md)）。
- **灵石（成就凭证）**：修士历练所得的成果结晶——一次成功的故障复盘、一个开源贡献、一张行业认证、一套自动化平台。灵石越多，江湖地位越高。

## ⚡ 天劫设定

修仙必渡劫，运维必历险。**天劫 = 生产事故 / 重大故障**。

| 天劫 | 运维对应 | 渡劫奖励 |
| --- | --- | --- |
| 小天劫 | 线上故障 / 宕机 | 排障经验 + 复盘报告 |
| 大天劫 | 重大事故 / 数据丢失 | 应急预案 + 团队信任 |
| 九九重劫 | 架构重构 / 全面迁移 | 架构能力 + 江湖声望 |

> 渡劫守则：不硬抗、不甩锅、先恢复、再复盘。每一次成功渡劫，修为大涨；每一次失败，也是修为——只要复盘到位。

## 📜 修行境界总纲

```
练气（0~6月） → 筑基（6月~2年） → 金丹（2~5年）
      ↓ 金丹出师，选定功法分支
化神（5~8年） → 炼虚（8~10年） → 合体（10~12年） → 大乘（12~15年） → 渡劫飞升（15年+）
```

三境九层（练气/筑基/金丹）为 **通识必修**；金丹出师后，修士可按灵根选择功法分支（见 [06-功法分支](06-功法分支.md)），冲击后续境界（见 [07-后续境界](07-后续境界.md)）。
