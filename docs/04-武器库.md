## 📌 武器使用心法

1. **少而精**：每个阶段主修 1-2 件核心武器，其余了解即可。
2. **兵器谱升级**：练气期用「命令 + 系统工具」，筑基期用「服务软件」，金丹期用「自动化 + 云原生平台」——武器跟着境界走。
3. **人剑合一**：武器要熟到「不用看文档」——配置、排错、文档都能独立完成。
4. 更多开源武器可查阅 [awesome-devops](https://github.com/haixing-lw/awesome-devops)（77 个精选项目）。
