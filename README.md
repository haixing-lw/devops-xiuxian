# 🧘 运维修仙之路 · Devops Xiuxian

> 一本给运维新人的「修仙功法总纲」：把从零基础到 **5 年运维经验（金丹期）** 的成长路线，设计成修仙体系——境界、功法、修为、历练、武器、突破，一步一步照着修，即可出师。

```
练气期（0~6月）  →  筑基期（6月~2年）  →  金丹期（2~5年）
  凡尘入道            系统运维小成          自动化·云原生·SRE
```

## 🏔 修仙世界观

在运维界，每一位新人都是一颗未经打磨的灵石。本功法按 **三境九层** 设计，每一层都有对应的：

| 要素 | 说明 |
| --- | --- |
| 📜 功法 | 本层主修的心法（学习主题与顺序） |
| 💠 修为经验 | 需要吃透的知识要点（内力） |
| ⚔️ 实操历练 | 动手实验与项目（打怪涨经验） |
| 🗡️ 武器 | 本层要熟练使用的软件工具（法宝） |
| 🔥 突破条件 | 达成即可突破到下一层的考核清单 |

突破不看年头，看修为。练满一层、通过突破考核，即晋升。

## 🗺 境界总览

| 境界 | 层 | 时间 | 江湖定位 | 核心功法 |
| --- | --- | --- | --- | --- |
| **练气期** | 练气一层 · 道基初成 | 0~2月 | 学徒 | 计算机基础 · Linux 入门 · 基础命令 |
| | 练气二层 · 灵气外放 | 2~4月 | 学徒 | 文件权限 · 用户组 · 文本处理 · 进程管理 |
| | 练气三层 · 气贯周天 | 4~6月 | 准运维 | 网络基础 · SSH · 防火墙 · Git |
| **筑基期** | 筑基一层 · 固本培元 | 6~10月 | 初级运维 | systemd · 日志 · 磁盘 · 定时任务 · 监控入门 |
| | 筑基二层 · 五行相生 | 10~16月 | 初级运维 | Shell 自动化 · Nginx · MySQL · Redis |
| | 筑基三层 · 法力初聚 | 16~24月 | 中级运维 | 备份恢复 · 安全加固 · 云服务器 · 虚拟化 |
| **金丹期** | 金丹一层 · 丹成二品 | 2~3年 | 高级运维 | Ansible 自动化 · Prometheus/Grafana · 日志体系 |
| | 金丹二层 · 丹成一品 | 3~4年 | 高级运维 | Docker · Compose · CI/CD · GitOps |
| | 金丹三层 · 金丹大成 | 4~5年 | SRE/架构师 | Kubernetes · Helm · 云平台 · 可观测性 · 稳定性治理 |

> 🎓 金丹三层突破后，即达成「5 年运维经验」出师标准。再往上，便是化神期（平台工程、架构设计、团队技术布道），功法中留有展望。

## 📖 如何使用本功法

1. **从练气一层开始**，逐层修炼，不要跳境界。
2. 每层先看 **功法** → 吃透 **修为经验** → 完成 **实操历练** → 熟练 **武器** → 通过 **突破条件**。
3. 每一层都有「预计修炼时长」，按自己的节奏调整，快慢皆可。
4. 武器清单全部来自 [haixing-lw/awesome-devops](https://github.com/haixing-lw/awesome-devops)（精选高质量运维开源项目库），需要哪件法宝，点链接直接取用。
5. 遇到瓶颈：回到上一层补修为，或查看对应武器的官方文档。
